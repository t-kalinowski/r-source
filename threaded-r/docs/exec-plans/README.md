# Execution Plans

Use this directory for first-class implementation plans.

- `active/`: current workstreams.
- `completed/`: finished plans with outcomes.
- `PLAN_TEMPLATE.md`: starting point for new plans.

Each plan should include:

1. Objective and non-goals.
2. Invariants touched.
3. Step checklist.
4. Validation ladder (tests/smokes/benchmarks).
5. Decision log with dates.
6. Exit criteria and status.
